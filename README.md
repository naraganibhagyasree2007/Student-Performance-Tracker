# Student Performance Tracker

A Python-based project for analyzing and tracking student academic performance using Pandas and Matplotlib.

## 📌 Project Description

The Student Performance Tracker reads student marks from a CSV file and automatically calculates total marks, percentage, grade, and Pass/Fail status.

It also provides class performance statistics, individual student search, and a performance visualization.

## 🎯 Objectives

- Calculate total marks and percentage
- Assign grades automatically
- Determine Pass/Fail status
- Analyze overall class performance
- Search for individual student performance
- Visualize student performance

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## ✨ Features

- Student data management using CSV
- Automatic total and percentage calculation
- Automatic grade assignment
- Pass/Fail result
- Student search using Student ID
- Class performance summary
- Performance visualization
